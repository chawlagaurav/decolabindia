# Motion asset sources

The cinematic loops use footage downloaded from Pexels and adapted for web playback under the Pexels license.

- Residential film: [Modern luxury interior with open design](https://www.pexels.com/video/modern-luxury-interior-with-open-design-38675643/)
- Commercial film: [Luxurious shopping mall tour in the city](https://www.pexels.com/video/luxurious-shopping-mall-tour-in-the-city-34738710/)

Both files are trimmed, color graded, muted, resized, compressed, and encoded as seamless H.264 loops.
